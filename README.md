## 📖 Project Overview
This project is a modern take on the classic arcade game, Tetris[cite: 1]. Developed using Python[cite: 1], it features smooth gameplay, score tracking, and intuitive controls. The project also includes an MCQ (Multiple Choice Question) module integrated into the logic (via `mcq.py`)[cite: 1]. It's a perfect showcase of object-oriented programming, game loops, and event handling in Python.

## 🛠️ Main Technology Used
*   **Python:** The core logic and structure of the game are written entirely in Python[cite: 1].

## ✨ Main Features
*   **Classic Gameplay:** Standard Tetris mechanics including falling blocks, rotation, and line clearing[cite: 1].
*   **Custom MCQ Module:** Integration of a unique multiple-choice question feature (`mcq.py`) within the system[cite: 1].
*   **Score Tracking:** Real-time point calculation based on cleared lines.
*   **Keyboard Controls:** Smooth and responsive movement using arrow keys.
